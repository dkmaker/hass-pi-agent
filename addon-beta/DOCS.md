# Pi Agent for Home Assistant (Beta)

The **beta channel** of Pi Agent — pre-release builds for trying new features
before they ship in the stable add-on.

This is the same add-on as the stable **Pi Agent for Home Assistant**, built from
the `beta` branch and published as pre-release versions (`X.Y.Z-beta.N`). Use it
to test upcoming changes; expect rougher edges than the stable channel.

## How it works

- It installs as a **separate add-on** (slug `pi_agent_beta`) with its own icon in
  the sidebar (**Pi Agent Beta**). You can run it alongside the stable add-on.
- Its configuration is independent from the stable add-on's — set your AI provider,
  model, and API key from the in-app setup (the ⚙️ button) just like the stable one.
- Updates arrive whenever a new beta is published; Home Assistant offers the update
  on the add-on's Info tab.

## Which one should I use?

- **Stable** (Pi Agent for Home Assistant): for everyday use.
- **Beta** (this add-on): to preview and help test new features.

If you're not actively testing, use the stable add-on.

See the stable add-on's documentation for full usage details — the feature set is
the same, only newer.
